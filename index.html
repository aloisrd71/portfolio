Mon stage

Dans le cadre de ma première année de BTS SIO SISR, j'ai réalisé un stage au sein de l'entreprise Plasteurop.

Ce stage m'a permis de découvrir concrètement le fonctionnement d'un environnement informatique professionnel et de mettre en pratique différentes compétences liées aux systèmes, aux réseaux et au support informatique.

Au cours de mon stage, j'ai notamment travaillé sur la configuration de postes de travail, l'utilisation de PowerShell, la documentation informatique et le logiciel ODA.

Mes principales missions

  • Configuration de postes

    Configuration de nouveaux ordinateurs, intégration au domaine de l'entreprise, installation des logiciels nécessaires et mises à jour du système.

  • PowerShell

    Utilisation de scripts PowerShell afin d'automatiser certaines tâches, notamment la suppression d'applications système HP.

  • ODA

    Saisie de données et découverte du logiciel ODA, utilisé pour répertorier et suivre les observations liées aux bonnes pratiques de sécurité.

  • Documentation

    Création d'un mode opératoire destiné à expliquer l'utilisation du logiciel ODA aux utilisateurs et aux administrateurs.

  • Cybersécurité

    Sensibilisation aux différentes formes de cyberattaques, à leurs risques, leurs conséquences et aux précautions permettant de mieux s'en protéger.

Mes deux projets

Projet 1

Infrastructure réseau

L'objectif de ce projet était de mettre en place une nouvelle infrastructure réseau pour la société GEFFII, composée de deux réseaux locaux : un réseau Ouest et un réseau Est.

Objectif

Permettre aux différents postes et équipements de communiquer entre eux et permettre aux deux réseaux d'accéder à Internet.

Technologies utilisées

  • Linux
  • IP
  • VLSM
  • Routage
  • NAT
  • DNS
  • iptables

Comment le projet a été réalisé ?

  1. Création du plan réseau

    Les réseaux GEFFII Ouest et GEFFII Est ont été définis avec différents sous-réseaux. Le plan d'adressage utilise notamment la technique VLSM pour répartir les adresses IP.

  2. Configuration des routeurs

    Les routeurs Linux ont été configurés avec leurs adresses IP, leurs passerelles et leurs paramètres réseau.

  3. Activation du routage

    Le routage IP a été activé afin de permettre aux routeurs de transmettre les paquets entre les différents réseaux.

  4. Mise en place des routes

    Des routes statiques ont été ajoutées afin que les routeurs puissent connaître les réseaux distants.

  5. Mise en place du NAT

    Le NAT a été configuré sur le routeur prestataire afin que les machines du réseau local puissent accéder à Internet.

  6. Tests

    Des tests de ping, de communication entre les réseaux, d'accès à Internet et de résolution DNS ont permis de vérifier le bon fonctionnement de l'infrastructure.

Projet 2

Infrastructure serveur

Le deuxième projet consistait à mettre en place une infrastructure serveur permettant de gérer les utilisateurs, les fichiers, les bases de données et l'intranet de la société.

Objectif

Installer et configurer les différents services nécessaires au fonctionnement du système informatique de GEFFII.

Technologies utilisées

  • Windows Server
  • Active Directory
  • SQL Server
  • IIS
  • HTML
  • PHP
  • Réseau

Comment le projet a été réalisé ?

  1. Installation du serveur

    Un serveur Windows Server a été installé et configuré avec un nom de machine, une adresse IP et un domaine.

  2. Gestion des utilisateurs

    Une organisation des salariés a été mise en place afin que chaque utilisateur puisse se connecter avec son propre nom d'utilisateur et son mot de passe.

  3. Gestion des fichiers

    Des espaces de stockage centralisés ont été prévus pour les utilisateurs. Les lecteurs réseau T, U et V permettent respectivement de travailler, consulter des ressources en lecture seule et échanger des fichiers.

  4. Installation de SQL Server

    Le SGBDR SQL Server a été installé afin d'héberger les bases de données demandées pour les activités de GEFFII.

  5. Installation d'IIS

    Le serveur IIS a été installé pour mettre en place le serveur Web et l'intranet de l'entreprise.

  6. Création de la page Web

    Une page d'accueil utilisant du HTML et du PHP a été prévue pour l'intranet.

Mes quatre semaines de stage

  1. Semaine 1

    Configuration de postes de travail, saisie des données ODA et début de la conception d'un mode opératoire.

  2. Semaine 2

    Configuration de postes, conception du mode opératoire ODA et utilisation d'un script PowerShell pour supprimer certaines applications HP.

  3. Semaine 3

    Configuration d'un nouveau poste, transfert des documents d'une session utilisateur et poursuite de la création de la fiche d'installation.

  4. Semaine 4

    Configuration d'un poste utilisateur, finalisation de la fiche d'installation et sensibilisation aux cyberattaques avec la DGSI.

Bilan

Ces différents travaux m'ont permis de mieux comprendre le fonctionnement d'une infrastructure informatique complète. J'ai pu travailler aussi bien sur la partie réseau que sur la partie serveur.

Le premier projet m'a permis de comprendre comment plusieurs réseaux peuvent communiquer grâce au routage, aux routes statiques, au DNS et au NAT. Le deuxième projet m'a permis de découvrir l'administration des serveurs, la gestion des utilisateurs, les bases de données et les services Web.
